# 패턴 선택 기준

SKILL.md 2단계(정보 구조 선택)와 4단계(패턴과 업무 의미 연결)에서 참고한다. 참고 서비스의 패턴을 다른 분야에 옮길 때는 **왜 그 패턴이 거기서 통했는지**를 먼저 적고, 같은 조건이 새 서비스에도 있는지 확인한다.

## 1. 주요 탐색 구조

| 패턴 | 적합한 조건 | 피해야 할 조건 |
|---|---|---|
| 하단 탭 (모바일) | 독립적으로 자주 방문하는 목적지 3~5개, 각 탭이 자체 상태를 유지해야 함 | 목적지가 2개 이하이거나 6개 이상, 탭 간 순서가 있는 업무 |
| 사이드바 (웹) | 목적지 6개 이상, 그룹이 필요한 관리형 화면 | 소비형 콘텐츠 서비스의 1차 탐색 |
| 상단 세그먼트 | 같은 객체를 다른 관점(진행 중/완료, 내 것/전체)으로 보는 경우 | 서로 다른 객체 간 이동 |
| 햄버거/더보기 | 드물게 쓰는 설정·계정·도움말 | 핵심 업무의 진입점 |
| 단일 흐름(탭 없음) | 한 번에 하나의 업무만 수행하는 도구형 앱, 온보딩 | 재방문 목적지가 여러 개인 서비스 |

판단 질문: "이 화면에 바로 들어가서 할 일이 있는가?" 그렇다면 1차 탐색 후보, 아니면 상세나 설정 안으로 넣는다.

## 2. 목록과 상세

| 패턴 | 적합한 조건 |
|---|---|
| 요약 카드 → 목록 → 상세 | 객체 수가 많고 비교·선택이 핵심 (상품, 매물, 과정) |
| 다음 행동 우선 홈 | 진행 중인 업무가 1~3개이고 완료가 목표 (배송, 예약, 신청 진행) |
| 상세 안 탭·섹션 | 같은 객체의 하위 정보가 3종 이상 (정보/리뷰/문의) |
| 인라인 펼침 | 하위 정보가 짧고 목록을 떠나지 않아야 할 때 |
| 모달/시트 상세 | 복귀가 잦고 원래 위치·필터를 그대로 유지해야 할 때 |

상세에서 복귀할 때 목록의 스크롤 위치·필터·선택 상태가 유지되는지 명세에 적는다.

## 3. 입력과 단계

| 패턴 | 적합한 조건 |
|---|---|
| 단일 폼 | 필수 입력 7개 이하, 순서 의존 없음 |
| 단계형(위저드) | 앞 단계 결과가 뒤 단계 선택지를 바꿈, 또는 결제·승인처럼 되돌릴 수 없는 전환이 끝에 있음 |
| 점진적 공개 | 선택에 따라 필요한 입력이 달라짐 (배송 방법 → 주소) |
| 인라인 편집 | 이미 저장된 값의 일부만 고치는 재방문 작업 |

단계형을 선택했다면 단계별 저장 여부, 뒤로 갔을 때 입력 보존, 중간 이탈 후 재진입 지점을 표로 정한다.

## 4. 검색과 필터

- 검색: 사용자가 이미 대상을 아는 경우. 결과 수와 "결과 없음"의 다음 행동을 정한다.
- 필터: 조건을 좁혀가며 고르는 경우. 활성 조건 표시와 초기화 버튼을 둔다.
- 정렬: 비교 기준이 하나로 명확할 때만 노출한다.
- 모바일은 필터를 시트로, 웹은 좌측 패널이나 상단 칩으로 두는 것이 일반적이나 조건 수에 맞춘다.

## 5. 상태 표현

| 상태 종류 | 표현 원칙 |
|---|---|
| 업무 상태 (확정, 취소, 배송 중) | 라벨 텍스트 + 색. 색만으로 구분하지 않는다 |
| 화면 상태 (로딩, 저장 중) | 해당 영역에만 표시, 중복 실행 차단 |
| 빈 결과 | 이유와 다음 행동을 함께 제시 |
| 오류 | 입력 보존, 오류 위치 표시, 재시도 경로 |
| 권한 제한 | 무엇이 막혔고 어떻게 얻는지 안내 |

## 6. 다른 분야로 매핑할 때

1. 참고 서비스의 핵심 객체와 업무 상태를 먼저 적는다. (예: 투자 앱 — 종목, 보유, 주문 상태)
2. 새 서비스의 객체와 상태를 같은 표에 나란히 적는다. (예: 학습 앱 — 과정, 수강, 진도 상태)
3. 대응되는 것만 패턴을 가져오고, 대응이 없는 요소는 버린다. 참고 서비스의 탭 수·순서를 그대로 쓰지 않는다.
4. 분야 의존적 의미(투자의 빨강/초록, 배달의 실시간 지도)는 새 분야에서 같은 의미가 성립하는지 확인한 뒤에만 가져온다.
5. 로고·원문 문구·고유 일러스트는 복제하지 않는다. 위계와 동선만 가져온다.

## 7. 플랫폼별 조정

| 항목 | 모바일 | 웹 |
|---|---|---|
| 1차 탐색 | 하단 탭, 3~5개 | 상단 메뉴 또는 사이드바 |
| 상세 | 전체 화면 푸시, 뒤로가기로 복귀 | 분할 화면 또는 모달, URL 로 직접 진입 가능 |
| 일괄 처리 | 길게 눌러 선택 모드 | 체크박스 + 상단 액션 바 |
| 입력 | 키보드가 가리지 않게 스크롤, 하단 고정 버튼 | 폼 하단 버튼, Enter 제출 여부 명시 |
| 복귀 | 시스템 BACK/제스처와 내부 뒤로가기 일치 | 브라우저 뒤로가기가 모달·필터 상태와 충돌하지 않게 |
